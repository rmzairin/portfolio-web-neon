# 🌆 Portfolio Web — Neon Edition

Eksperimen desain web bergaya **neon/cyberpunk**: dominan CSS custom (glow effect, gradient, animasi transisi) dipadukan JavaScript vanilla buat interaktivitasnya. Dibangun tanpa framework, murni dari nol.

## 🧩 Isi Project

```
portfolio-web-neon/
├── image/        # Aset gambar
├── index.html    # Struktur halaman
├── style.css     # Efek neon, layout, animasi
└── script.js     # Interaksi & behavior halaman
```

<br>

## 🖥️ Cara Coba di Lokal

Gak perlu install dependency apapun, tinggal clone lalu buka filenya:

```bash
git clone https://github.com/rmzairin/portfolio-web-neon.git
cd portfolio-web-neon
```

Buka `index.html` di browser, atau jalanin local server kalau mau:

```bash
python -m http.server 5500
```
